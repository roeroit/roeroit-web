🧱 L'anatomia di un tag: apri, scrivi, chiudiLa anatomía de una etiqueta: abre, escribe, cierra

Quasi tutti i tag HTML funzionano come un panino: un tag di apertura <p>, il contenuto in mezzo e un tag di chiusura con la barra </p>. Esempio: <h1>Ciao Riccardo!</h1>. Alcuni tag non hanno contenuto e non si chiudono, come <img> e <input>.

Casi todas las etiquetas HTML funcionan como un sándwich: una etiqueta de apertura <p>, el contenido en el medio y una de cierre con barra </p>. Ejemplo: <h1>¡Hola Ricardo!</h1>. Algunas etiquetas no tienen contenido y no se cierran, como <img> e <input>.

1. Lo scheletro standard di qualsiasi pagina1. El esqueleto estándar de cualquier página

Questo è il file minimo che ogni browser si aspetta. Il blocco <head> contiene informazioni per il browser e per Google; il <body> contiene ciò che vede l'utente.

Este es el archivo mínimo que todo navegador espera. El bloque <head> tiene información para el navegador y para Google; el <body> tiene lo que ve el usuario.

HTML5
<!DOCTYPE html>
<html lang="it">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Titolo che appare nella scheda del browser</title>
  </head>
  <body>
    <!-- Tutto quello che scrivi qui è visibile all'utente -->
    <h1>Benvenuto nel mio sito</h1>
    <p>Questo è un paragrafo normale.</p>
  </body>
</html>

📦 Il segreto del CSS: tutto è una scatola (Box Model)El secreto de CSS: todo es una caja (Box Model)

Nel web ogni elemento, anche un titolo o una foto rotonda, è in realtà una scatola rettangolare. Capire la differenza tra padding (spazio interno) e margin (spazio esterno) è la chiave del layout.

En la web cada elemento, incluso un título o una foto redonda, es en realidad una caja rectangular. Entender la diferencia entre padding (espacio interior) y margin (espacio exterior) es la clave de la maquetación.

MARGIN — spazio esterno, allontana gli altri elementiMARGIN — espacio exterior, aleja a los demás elementos
BORDER — il bordo (visibile o invisibile)BORDER — el borde (visible o invisible)
PADDING — spazio interno tra bordo e contenutoPADDING — espacio interior entre borde y contenido
CONTENUTO (testo o immagine)CONTENIDO (texto o imagen)

1. Come si scrive una regola CSS1. Cómo se escribe una regla CSS

Selettore (a chi applico lo stile) + proprietà: valore; dentro le graffe. Il punto davanti al nome (.card) indica una classe, che in HTML si assegna con class="card".

Selector (a quién aplico el estilo) + propiedad: valor; dentro de llaves. El punto delante del nombre (.card) indica una clase, que en HTML se asigna con class="card".

CSS
/* Selettore { proprietà: valore; } */
h1 {
  color: #4f46e5;          /* colore del testo */
  font-size: 28px;         /* dimensione */
  text-align: center;      /* allineamento */
}

.card {
  background: white;       /* sfondo */
  padding: 20px;           /* spazio interno */
  margin: 16px;            /* spazio esterno */
  border-radius: 12px;     /* angoli arrotondati */
  box-shadow: 0 4px 6px rgba(0,0,0,0.1);  /* ombra morbida */
}

2. Dove si scrive il CSS?2. ¿Dónde se escribe el CSS?

  • Dentro <style> nel <head>: comodo per una sola pagina (lo usiamo nel laboratorio).
  • In un file separato style.css collegato con <link rel="stylesheet" href="style.css">: il modo professionale, perché lo stesso stile vale per tutte le pagine del sito.
  • Nell'attributo style="...": solo per prove veloci, diventa disordinato.
  • Dentro de <style> en el <head>: cómodo para una sola página (lo usamos en el laboratorio).
  • En un archivo aparte style.css enlazado con <link rel="stylesheet" href="style.css">: la forma profesional, porque el mismo estilo sirve para todas las páginas del sitio.
  • En el atributo style="...": solo para pruebas rápidas, se vuelve desordenado.

Colori: si scrivono per nome (red), in esadecimale (#4f46e5) o in rgb(79, 70, 229). Per scegliere palette armoniose prova coolors.co.

Colores: se escriben por nombre (red), en hexadecimal (#4f46e5) o en rgb(79, 70, 229). Para elegir paletas armoniosas prueba coolors.co.

🤝 Nota del tuo mentoreNota de tu mentor

Riccardo, non spaventarti con la parola "database". Un database relazionale è come un foglio Excel super ordinato e velocissimo: ha tabelle con colonne (Nome, Email) e righe (i record). Per parlargli si usa il linguaggio SQL.

Ricardo, no te asustes con la palabra "base de datos". Una base relacional es como una planilla de Excel súper ordenada y rapidísima: tiene tablas con columnas (Nombre, Email) y filas (los registros). Para hablarle se usa el lenguaje SQL.

⚠️ La regola d'oro del WHERELa regla de oro del WHERE

Un UPDATE o DELETE senza WHERE modifica o cancella tutte le righe. Prima di cancellare, fai sempre una SELECT con lo stesso WHERE per vedere cosa toccherai.

Un UPDATE o DELETE sin WHERE modifica o borra todas las filas. Antes de borrar, haz siempre un SELECT con el mismo WHERE para ver qué vas a tocar.

🌐 E in un sito vero?¿Y en un sitio real?

Il database vive sul server, non nel browser. Il sito manda i dati del modulo a un programma sul server (scritto in PHP, Node.js o Python) che esegue queste stesse query SQL. Per un sito vetrina spesso non serve: basta un link WhatsApp o un servizio di moduli (lo vedremo nel Livello 4).

La base de datos vive en el servidor, no en el navegador. El sitio envía los datos del formulario a un programa en el servidor (escrito en PHP, Node.js o Python) que ejecuta estas mismas consultas SQL. Para un sitio vidriera muchas veces no hace falta: alcanza con un enlace de WhatsApp o un servicio de formularios (lo vemos en el Nivel 4).
