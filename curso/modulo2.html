Fase 1

L'Anatomia di una Pagina Web Professionale

Come strutturano i loro progetti i professionisti usando HTML semantico.

💡 Le 5 Sezioni Sacre di qualsiasi sito
Che si tratti del sito di un ristorante italiano, di uno studio di avvocati o di una landing page, c'è sempre uno schema vincente: Header (Logo e Menu) $\rightarrow$ Hero Section (Titolo d'impatto con pulsante d'azione) $\rightarrow$ Features / Servizi (Griglia a colonne) $\rightarrow$ Contatto (Form per ricevere clienti) $\rightarrow$ Footer (Copyright e contatti).

1. I Tag Semantici (Non usare solo <div>!)

Nel Livello 1 abbiamo visto i tag base. Ora vediamo i tag che fanno capire a Google e agli smartphone cosa c'è nella pagina:

HTML Semantico 
<body>
  <!-- 1. Intestazione con navigazione -->
  <header>
    <nav>...menu con link...</nav>
  </header>

  <!-- 2. Contenuto principale -->
  <main>
    <section class="hero">...copertina con titolo e bottone...</section>
    <section class="servizi">...griglia delle offerte...</section>
    <section class="contatti">...modulo email...</section>
  </main>

  <!-- 3. Piè di pagina -->
  <footer>
    <p>© 2026 Creato da Riccardo</p>
  </footer>
</body>
📝 Verifica Rapida: Sezione 1
1. Perché è molto meglio usare <header>, <nav> e <footer> invece di usare solo <div> dappertutto?
Fase 2

I Due Grandi Maestri del Layout: Flexbox & CSS Grid

Come mettere qualsiasi elemento dove vuoi senza impazzire.

🤝 La Regola Chiara del tuo Mentor
Riccardo, un tempo allineare elementi in CSS era un incubo. Oggi c'è una regola d'oro chiarissima:
• Usa Flexbox per cose su una riga (es: menu con logo a sinistra e link a destra).
• Usa CSS Grid per griglie a due dimensioni (es: schede prodotti 3x3 o gallerie di foto).

1. Flexbox in 3 righe magiche

CSS Flexbox 
.menu-moderno {
  display: flex;
  justify-content: space-between; /* Spinge logo a sinistra e link a destra */
  align-items: center;            /* Centra perfettamente in verticale */
}

2. CSS Grid: Griglie Automatiche che si adattano da sole

Questa riga singola è il segreto più potente del web moderno. Dice al browser: "Crea colonne che si adattano automaticamente, con larghezza minima di 260px":

CSS Grid Magico 
.griglia-servizi {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 20px; /* Spazio tra le card */
}
📝 Verifica Rapida: Sezione 2
1. Qual è lo strumento perfetto per allineare gli elementi di una barra di navigazione orizzontale?
Fase 3

Design Responsive: Funzionare su Cellulari & PC

Più del 70% dei visitatori userà lo smartphone. Ecco come adattare il sito.

📱 La Media Query: L'interruttore del Design
Una Media Query è una condizione CSS che dice: "Se lo schermo è più stretto di 768px (un cellulare o tablet verticale), applica queste nuove regole (es: metti il menu in colonna invece che in riga)".
CSS Responsive 
/* Per computer (schermi grandi) */
.menu {
  display: flex;
  flex-direction: row;
}

/* Quando lo schermo è piccolo (Smartphone) */
@media (max-width: 768px) {
  .menu {
    flex-direction: column; /* Gli elementi vanno uno sotto l'altro */
    text-align: center;
  }
}
📝 Verifica Rapida: Sezione 3
1. A cosa serve la regola @media (max-width: 768px)?
