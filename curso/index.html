Modulo 1

Le Fondamenta del Web: HTML5

Come creare lo scheletro di qualsiasi sito web sul pianeta.

💡 Come pensare a HTML
Pensa a una casa: HTML sono i mattoni, le pareti e le stanze. CSS sarà la vernice e i mobili, mentre il Database sarà lo scantinato dove archivi le provviste.

1. La struttura universale di un file HTML

Ogni pagina web inizia sempre con questa struttura fissa. Il computer legge dall'alto verso il basso:

HTML 
<!DOCTYPE html>
<html lang="it">
  <head>
    <meta charset="UTF-8">
    <title>Il mio primo sito</title>
  </head>
  <body>
    <h1>Ciao, sono Riccardo!</h1>
    <p>Sto imparando il web design da zero.</p>
  </body>
</html>

2. I mattoni essenziali (I Tag)

  • <h1> fino a <h6>: Titoli da quello principale fino al più piccolo.
  • <p>: Paragrafi di testo normale.
  • <a href="url">: Link cliccabili per andare su un'altra pagina.
  • <img src="foto.jpg" alt="...">: Immagini sul sito.
  • <form> e <input>: Caselle di testo e pulsanti (fondamentali per inviare dati al database!).

Modulo 2

Stile, Layout & Template: La Magia di CSS3

Come rendere bello un sito e usare template per andare 10 volte più veloci.

💡 La Regola d'Oro del Web Designer Moderno
I professionisti non creano quasi mai tutto da zero. Usano template o librerie (come Bootstrap, Tailwind o HTML5 Templates) e poi personalizzano i colori, i testi e la struttura!

1. Come funziona il CSS: Regola di Base

Il CSS dice al browser: "Prendi questo elemento e dagli queste proprietà visive".

CSS 
/* Selettore { Proprietà: Valore; } */
h1 {
  color: #4f46e5;        /* Colore del testo (Viola moderno) */
  font-size: 32px;       /* Dimensione del carattere */
  text-align: center;    /* Centra il testo */
}

.bottone-verde {
  background-color: #10b981; /* Sfondo verde smeraldo */
  color: white;              /* Testo bianco */
  border-radius: 8px;        /* Bordi arrotondati */
  padding: 10px 20px;        /* Spazio interno */
}

2. Che cos'è un "Template" (Plantilla)?

Un Template è una pagina web già disegnata e programmata da designer esperti con HTML, CSS e immagini pronte.

  • Vantaggio 1: Risparmi ore di lavoro di grafica.
  • Vantaggio 2: È già ottimizzato per funzionare perfettamente sia su smartphone che su computer (Responsive).
  • Cosa devi fare tu: Aprire il file del template, trovare i testi/immagini che vuoi cambiare e sostituirli con i tuoi!
🎨 Laboratorio CSS: Cambia il colore di sfondo e il bordo!

Il Cervello e la Memoria: Backend & SQLite Web

Come fa un sito a ricordarsi gli utenti. Esegui vero codice SQL direttamente dal browser!

🤝 Nota del tuo Mentor
Riccardo, questo è il passo che separa un semplice grafico da un vero sviluppatore web! Non avere paura dei database: alla fine sono solo tabelle tipo Excel, ma super veloci e sicure.

1. Il viaggio di un dato: Come funziona il Web?

  1. Frontend (Il Browser): L'utente scrive il suo nome e la sua email in un modulo HTML e clicca "Invia".
  2. Backend (Il Server): Riceve le informazioni, controlla che non ci siano errori e le prepara.
  3. Database (La Memoria): Salva le informazioni in una riga di una tabella in modo permanente.

2. Le 4 Operazioni Fondamentali: Il CRUD con Comandi SQL

In qualsiasi database al mondo (SQLite, MySQL, Postgres) si usano questi comandi SQL:

  • C (Create): INSERT INTO tabella VALUES (...);
  • R (Read): SELECT * FROM tabella;
  • U (Update): UPDATE tabella SET colonna = valore WHERE id = ...;
  • D (Delete): DELETE FROM tabella WHERE id = ...;

Il Tuo Superpotere: Sviluppo Web con Intelligenza Artificiale

Come usare ChatGPT, Claude o Gemini come tuo copilota personale per creare codice.

🤖 Perché imparare prima HTML e CSS se c'è l'IA?
L'IA è come un'auto da corsa di Formula 1: se non sai dove sono il volante o i freni, ti schianterai. Imparando le basi con il tuo mentore, saprai cosa chiedere all'IA e come riconoscere e correggere quando commette un errore!

1. La Formula Magica per i Prompt di Codice

Quando chiedi codice all'IA, segui sempre questa struttura in 3 parti:

  1. Ruolo e Contesto: "Agisci come esperto di web design per principianti."
  2. Compito Specifico: "Creami una barra di navigazione moderna con logo a sinistra e 3 link a destra."
  3. Formato di Uscita: "Dammi solo codice HTML e CSS pulito, senza complicazioni e spiegato riga per riga."

2. Prompt Pronti all'Uso (Copia e Incolla)

Esempio 1: Personalizzare una sezione di un Template
"Ho scaricato un template HTML. Ecco il codice di una card: [incolla codice]. Voglio cambiare lo sfondo in blu scuro, aggiungere un'ombra morbida e mettere un pulsante verde WhatsApp."
Esempio 2: Risolvere un errore (Debugging)
"Sto creando un modulo di contatto in HTML. Quando clicco il pulsante non invia nulla. Ecco il mio codice: [incolla codice]. Dimmi dove sta l'errore e come correggerlo in modo semplice."
Esempio 3: Connettere il form al Database SQLite
"Ho questo form HTML con campi Nome ed Email. Voglio salvare questi dati in un database SQLite. Spiegami i passaggi necessari in modo semplice e guidato passo dopo passo."
