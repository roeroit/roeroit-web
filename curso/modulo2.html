1. I tag semantici (non usare solo <div>!)1. Las etiquetas semánticas (¡no uses solo <div>!)

Nel Livello 1 abbiamo visto i tag base. Questi tag funzionano come un <div>, ma il nome spiega cosa contengono: Google, i lettori di schermo per non vedenti e chi leggerà il tuo codice capiscono subito la pagina.

En el Nivel 1 vimos las etiquetas básicas. Estas funcionan como un <div>, pero el nombre explica qué contienen: Google, los lectores de pantalla para no videntes y quien lea tu código entienden enseguida la página.

HTML Semantico
<body>
  <!-- 1. Intestazione con navigazione -->
  <header>
    <nav> ...link del menu... </nav>
  </header>

  <!-- 2. Contenuto principale (uno solo per pagina) -->
  <main>
    <section class="hero"> ...titolo e pulsante... </section>
    <section id="servizi"> ...griglia di card... </section>
    <section id="contatti"> ...modulo... </section>
  </main>

  <!-- 3. Piè di pagina -->
  <footer>
    <p>&copy; 2026 Creato da Riccardo</p>
  </footer>
</body>

Trucco del menu: se una sezione ha id="servizi", il link <a href="#servizi"> porta direttamente lì. Così funzionano i menu delle pagine singole.

Truco del menú: si una sección tiene id="servizi", el enlace <a href="#servizi"> lleva directo ahí. Así funcionan los menús de las páginas únicas.

Fase 2

I Due Maestri del Layout: Flexbox & CSS Grid

Los Dos Maestros de la Maquetación: Flexbox & CSS Grid

Come mettere qualsiasi elemento dove vuoi, senza impazzire.

Cómo poner cualquier elemento donde quieras, sin volverte loco.

🤝 La regola chiara del tuo mentoreLa regla clara de tu mentor

Riccardo, un tempo allineare elementi in CSS era un incubo. Oggi la regola è semplice:

  • Usa Flexbox per elementi in una riga o in una colonna (es. menu con logo a sinistra e link a destra).
  • Usa CSS Grid per griglie a due dimensioni (es. card dei prodotti, gallerie di foto).

Ricardo, antes alinear elementos en CSS era una pesadilla. Hoy la regla es simple:

  • Usa Flexbox para elementos en una fila o una columna (ej. menú con logo a la izquierda y enlaces a la derecha).
  • Usa CSS Grid para grillas de dos dimensiones (ej. tarjetas de productos, galerías de fotos).

1. Flexbox in 3 righe1. Flexbox en 3 líneas

CSS Flexbox
.menu {
  display: flex;
  justify-content: space-between; /* distribuisce in orizzontale */
  align-items: center;            /* centra in verticale */
  gap: 16px;                      /* spazio tra gli elementi */
}

2. CSS Grid: griglie che si adattano da sole2. CSS Grid: grillas que se adaptan solas

Questa riga è uno dei segreti più potenti del web moderno. Dice al browser: "crea tante colonne quante ne entrano, ognuna larga almeno 260px". Sul PC vedrai 3 colonne, sul cellulare 1, senza scrivere altro.

Esta línea es uno de los secretos más potentes de la web moderna. Le dice al navegador: "crea tantas columnas como entren, cada una de al menos 260px". En la PC verás 3 columnas, en el celular 1, sin escribir nada más.

CSS Grid
.griglia-servizi {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 20px;
}

Design Responsive: Funzionare su Cellulare e PC

Diseño Responsive: Funcionar en Celular y PC

La maggior parte dei visitatori di un'attività locale arriva dallo smartphone. Ecco come adattare il sito.

La mayoría de los visitantes de un negocio local llega desde el smartphone. Así se adapta el sitio.

⚠️ La riga che non deve mai mancareLa línea que nunca debe faltar

Senza questo tag nel <head>, il cellulare mostra il sito "rimpicciolito" come su un PC e le media query non funzionano bene:

Sin esta etiqueta en el <head>, el celular muestra el sitio "achicado" como en una PC y las media queries no funcionan bien:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

📱 La media query: l'interruttore del designLa media query: el interruptor del diseño

Una media query è una condizione CSS: "se lo schermo è largo al massimo 768px (cellulare o tablet in verticale), applica queste regole in più".

Una media query es una condición CSS: "si la pantalla mide como máximo 768px (celular o tablet vertical), aplica estas reglas extra".

CSS Responsive
/* Per tutti gli schermi */
.menu { display: flex; flex-direction: row; }

/* Solo quando lo schermo è piccolo (smartphone) */
@media (max-width: 768px) {
  .menu {
    flex-direction: column;  /* gli elementi vanno uno sotto l'altro */
    text-align: center;
  }
}

Altri 3 trucchi responsive: img { max-width: 100%; } (le foto non escono mai dallo schermo), misure in % o rem invece di larghezze fisse, e pulsanti grandi almeno 44px per il dito.

Otros 3 trucos responsive: img { max-width: 100%; } (las fotos nunca se salen de la pantalla), medidas en % o rem en vez de anchos fijos, y botones de al menos 44px para el dedo.
