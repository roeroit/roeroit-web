Modulo 1: Contesto

Come è Nata la Web e Come Funziona Davvero Internet

Capire le origini e i meccanismi invisibili prima di toccare una singola riga di codice.

🕰️ Un po' di storia: Dal CERN a oggi
Nel 1989, uno scienziato britannico di nome Tim Berners-Lee lavorava al CERN in Svizzera. Gli scienziati avevano computer diversi che non si parlavano tra loro. Tim inventò il World Wide Web: un modo per collegare documenti di testo tramite link cliccabili (Hypertext). La prima pagina web della storia era purissimo testo nero su sfondo bianco con link blu. Oggi, quello stesso principio muove l'intera economia mondiale.

Modulo 3: Fondamenta

Le Fondamenta: HTML5 Spiegato Passo dopo Passo

Come dare forma e senso a ogni singolo elemento della tua pagina.

🧱 L'Anatomia di un Tag: Apri, Scrivi, Chiudi
La quasi totalità dei tag HTML funziona come un panino: un'etichetta di apertura <p>, il contenuto nel mezzo, e un'etichetta di chiusura con la barra </p>. Ad esempio: <h1>Ciao Riccardo!</h1>.

1. Lo scheletro standard di qualsiasi pagina

Questo è il file minimo che ogni browser (Chrome, Safari, Edge) si aspetta di ricevere:

HTML5 
<!DOCTYPE html>
<html lang="it">
  <head>
    <meta charset="UTF-8">
    <title>Titolo che appare nella scheda del browser</title>
  </head>
  <body>
    <!-- Tutto quello che scrivi qui dentro è visibile all'utente -->
    <h1>Benvenuto nel mio sito</h1>
    <p>Questo è un paragrafo normale.</p>
  </body>
</html>

2. I Mattoni più Usati Spiegati

  • <h1> a <h6> (Titoli): <h1> è il titolo principale del sito (ce ne deve essere solo uno per pagina per aiutare Google!), mentre <h2> e <h3> sono i sottotitoli.
  • <p> (Paragrafi): Per blocchi di testo leggibili.
  • <a href="https://..."> (Link): Il superpotere del web: collegare una pagina all'altra.
  • <img src="foto.jpg" alt="...">: Mostra un'immagine. L'attributo alt descrive la foto per non vedenti o se non carica.
  • <form> e <input>: La porta d'ingresso per ricevere dati dall'utente (nome, email, password, messaggi) e spedirli al database.

Modulo 4: Design

Dare Stile: CSS3, Box Model & Template

Come trasformare testo grezzo in un design moderno, attraente e ordinato.

📦 Il Segreto del CSS: Tutto è una Scatola (Box Model)
Nel web, ogni elemento (anche un titolo o un'immagine rotonda) è in realtà una scatola rettangolare. Capire la differenza tra Padding (spazio interno) e Margin (spazio esterno) è la chiave per padroneggiare il layout!
MARGIN (Spazio Esterno tra elementi)
BORDER (Il Bordo visibile o invisibile)
PADDING (Spazio Interno tra bordo e testo)
CONTENUTO (Il testo o l'immagine)

1. Come si scrive una regola CSS?

Sintassi CSS 
/* Selettore (A chi applico lo stile?) { Proprietà: Valore; } */
h1 {
  color: #4f46e5;        /* Colore del testo (Viola moderno) */
  font-size: 28px;       /* Dimensione */
  text-align: center;    /* Allineamento */
}

.card-speciale {
  background: white;     /* Sfondo */
  padding: 20px;         /* Spazio interno */
  border-radius: 12px;   /* Angoli arrotondati */
  box-shadow: 0 4px 6px rgba(0,0,0,0.1); /* Ombra morbida */
}

Il Cervello e la Memoria: Backend & SQLite Web

Come salvare utenti, ordini e informazioni in modo permanente con SQL vero.

🔒 100% Online & Sicuro: Nessun Download
Tutto questo banco di lavoro SQLite funziona direttamente nel tuo browser. Non devi installare programmi o scaricare file rischiosi.
🤝 Nota del tuo Mentor
Riccardo, non spaventarti quando senti parlare di "Database". Alla fine, una base di dati relazionale è come un foglio Excel super ordinato e velocissimo: ha tabelle con colonne (es: Nome, Email) e righe con i record.

1. Le 4 Operazioni Fondamentali (CRUD) con comandi SQL

  • C (Create / Creare): INSERT INTO tabella VALUES (...);
  • R (Read / Leggere): SELECT * FROM tabella;
  • U (Update / Modificare): UPDATE tabella SET colonna = valore WHERE id = ...;
  • D (Delete / Cancellare): DELETE FROM tabella WHERE id = ...;

Modulo 6: Futuro

Il Tuo Superpotere: Sviluppo Web con Intelligenza Artificiale

Come usare ChatGPT, Claude o Gemini come tuo copilota personale per creare codice senza bloccarti.

🤖 L'IA come copilota, tu sei il pilota
L'IA conosce tutto il codice del mondo, ma non ha gusto visivo né sa cosa vuole il tuo cliente. Ora che conosci i cimientos di HTML, CSS e database, puoi chiederle esattamente ciò che serve e capire le sue risposte.

1. La Formula Magica del Prompt

  1. Ruolo: "Agisci come programmatore web senior per principianti."
  2. Compito e Dettagli: "Creami una sezione contatti con campi Nome, Email e Telefono, con colori blu e bianco."
  3. Formato di Uscita: "Dammi solo codice HTML e CSS pulito, senza librerie esterne e commentato in italiano."

2. Prompt Pronti da Copiare

Esempio 1: Personalizzare una sezione
"Ho questa card HTML: [incolla codice]. Voglio cambiare lo sfondo in blu notte, aggiungere un bordo sottile grigio e centrare il pulsante WhatsApp."
Esempio 2: Risolvere un errore (Debugging)
"Ho scritto questo modulo HTML ma quando clicco il pulsante non invia nulla. Ecco il codice: [incolla codice]. Qual è l'errore e come lo sistemo in modo semplice?"
